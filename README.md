# Astronaut GPT (Astra AI) - Cosmic AI Prank Chat

A modern, high-tech AI Chat web app designed to mimic cutting-edge LLMs (ChatGPT / Claude / Gemini) with an **Astronaut / Deep Space theme**, built as an interactive prank site seamlessly monetized with Adsterra ad codes and smartlinks.

---

## 🚀 Key Features

1. **Modern AI Chat UI**:
   - ChatGPT-style dark mode with sleek glassmorphism and cosmic space accents.
   - Left sidebar with "New Mission", recent cosmic chat history, and "Upgrade to Astra Pro Plus".
   - Model selector dropdown: **Astronaut GPT-5 (Astra Ultra)**, **Astra-Thinking-o1**, and **Astra Light 4.5**.
   - Interactive prompt suggestions ("Physics Paradox", "Orbital Mechanics", "Cosmic Facts", "First Contact").
   - Realistic thinking animation with rotating space-telemetry status updates.

2. **Hilarious Cosmic Prank Logic**:
   - Responds to any user question with witty astronaut/deep-space explanations.
   - Cleverly gates "classified telemetry" behind cosmic sponsors, triggering direct ad clicks.
   - Periodic "Orbital Satellite Bandwidth Limit Reached" system modal.

3. **Adsterra Monetization Integrated**:
   - **Popunder / Social Bar Scripts** in `<head>`
   - **Top Responsive Banner**: 728x90 (Desktop) / 468x60 (Mobile/Tablet)
   - **Sidebar Vertical Banner**: 160x600
   - **Right Telemetry Panel Banners**: 300x250, 160x300, 320x50
   - **Native Ad Container**: Embedded directly in the main chat feed
   - **Direct Smartlink**: Automatically triggered on chat interactions, model switches, and upgrades.
